# わりかんノート iPhone版

## ファイル構成

- index.html：画面とiPhoneのホーム画面設定
- style.css：iPhone対応の表示・タップ領域・セーフエリア
- app.js：支出管理、精算計算、保存・復元、PWA登録
- manifest.json：アプリ名、起動方法、アイコン指定
- service-worker.js：アプリ一式のオフラインキャッシュ
- icons/：ホーム画面用のPNGアイコン（180 / 192 / 512px）

## iPhoneで使う

1. このフォルダーの中身を、アイコンも含めてHTTPSに対応するWebサーバーへ配置します。ルート配信・サブフォルダー配信の両方に対応しています。
2. iPhoneのSafariで公開URLを開きます。
3. 共有メニュー →「ホーム画面に追加」を選びます。「Webアプリとして開く」が表示された場合はオンにします。
4. ホーム画面のアイコンからオンラインで一度起動し、「オフライン利用の準備完了」を確認してください。その後は通信なしでも起動して記録できます。

HTMLを「ファイル」アプリから直接開く方法では、PWAの登録・オフライン起動はできません。この成果物はまだWeb公開していません。

## データの保存と移行

元のHTML版と同じ精算機能を使用できます。固定負担額、個別調整、編集、支払履歴にも対応しています。

記録は使用中のブラウザー／ホーム画面アプリ内に保存されます。端末間の自動同期はありません。元のHTML版で「バックアップ」したJSONをiPhoneへ送り、iPhone版の「復元」で読み込めます。Safariからホーム画面アプリへのデータ引き継ぎにも依存せず、必要なら同じ方法で移行してください。

iPhoneでは対応していればバックアップ時に共有シートが開きます。「ファイルに保存」で保管してください。復元は現在の記録を置き換えます。

## 更新と検証

配信ファイルを変更する場合はservice-worker.js内のキャッシュ名のバージョン（v1）も変更し、一式を配信してください。新しい版は、古い版を開いているアプリ・タブをすべて閉じた後に有効になります。入力途中の画面を自動で再読み込みしません。

プロジェクト直下で `node output/test_iphone_pwa.cjs` を実行できます。精算ロジックの回帰テスト、参照ファイル・アイコン、オフライン応答、サブフォルダー配信、旧キャッシュ削除範囲を検証します。サービスワーカーの検証は模擬環境によるものです。iPhone実機での表示・ホーム画面追加・オフライン起動は未確認です。

参考：[Appleのホーム画面追加手順](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)、[Service WorkerのHTTPS要件](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API)。
